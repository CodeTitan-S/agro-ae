# AgroAE: AI-Powered Crop Advisory Platform

An end-to-end agronomic intelligence platform featuring tabular ML crop recommendations and CV-based leaf disease diagnosis.

## Architecture
* **Frontend:** React (Vite)
* **Backend:** Python (FastAPI)
* **Database:** PostgreSQL
* **Machine Learning:** Scikit-learn (Tabular) & PyTorch/TensorFlow (Computer Vision)

## Repository Structure
* `/backend`: FastAPI application, REST endpoints, database migrations, and service layers.
* `/frontend`: React client interface and UI components.
* `/ml`: Jupyter notebooks, model training scripts, and evaluation metrics.
* `/docs`: System architecture diagrams, database schemas, and API documentation.
